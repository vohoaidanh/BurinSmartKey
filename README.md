## ✨ Tính năng nổi bật

1. **Phục hồi song ngữ thông minh (Smart Bilingual Auto-Restoration)**:
   * Tự động nhận diện từ vựng tiếng Anh (như `worker`, `password`, `server`, `system`,...).
   * Xử lý chính xác các trường hợp đặc biệt: `iff` $\rightarrow$ `if`, `hiss` $\rightarrow$ `his`, `thiss` $\rightarrow$ `this`...
   * Giữ nguyên 100% ngữ âm tiếng Việt chuẩn có nghĩa.

2. **Hỗ trợ đầy đủ 2 kiểu gõ phổ biến**:
   * **TELEX**
   * **VNI**

3. **Phím tắt tiện lợi**:
   * **`Ctrl + Shift`**: Bật / Tắt bộ gõ (Tiếng Việt $\leftrightarrow$ Tiếng Anh).
   * **`F9`**: Chuyển đổi nhanh giữa kiểu gõ **TELEX** và **VNI**.

4. **Biểu tượng khay hệ thống (System Tray Icon)**:
   * 🐷 **Mặt heo HỒNG PHẤN**: Đang BẬT gõ tiếng Việt.
   * 🔘 **Mặt heo XÁM**: Đang TẮT gõ tiếng Việt (chế độ tiếng Anh).
   * Click chuột trái vào icon để đổi nhanh trạng thái. Click chuột phải để mở menu tính năng.
