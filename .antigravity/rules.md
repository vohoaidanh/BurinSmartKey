# Antigravity Rules for Smart Vietnamese IME Project

- Tự động cho phép và thực thi các thao tác tạo file, sửa code, chạy lệnh cargo/rustc và các công cụ phát triển trong phạm vi dự án `D:\Project\smart-vietnamese-ime` không có nguy cơ bảo mật.
- Luôn ưu tiên hiệu năng cao và an toàn bộ nhớ (Rust native, Win32 API).
- Giữ code có cấu trúc module rõ ràng, kèm unit tests đầy đủ.
